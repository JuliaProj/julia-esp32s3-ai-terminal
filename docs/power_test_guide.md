# Julia 功耗测试指南

## 测试前提

- 开发板：微雪 ESP32-S3 1.85 寸 LCD 开发板。
- 串口：通常为 `COM5`，波特率 `115200`。
- 电源：记录实际供电电压；测试时不要同时从 USB 和外部电源供电，除非已确认板卡电源路径允许。
- 关闭串口日志自动脚本，避免测试过程中发送额外交互命令。
- 电流表应串联在板卡实际供电输入端，记录平均电流和峰值电流。

## 通用命令

```text
status
state <0-19>
screen-timeout 300
screen-wake
doze enter
doze exit
demo off
```

`state` 的编号按 `main/fsm/julia_fsm.h` 和 `docs/state_asset_matrix.md` 为准。每个状态建议等待至少 60 秒，记录稳定段平均值；对动画、Wi-Fi、语音播放等瞬态单独记录峰值。

## 建议测试矩阵

| 编号 | 场景 | 进入方法 | 记录重点 |
|---|---|---|---|
| P0 | 冷启动 | 重启后等待稳定 | 启动峰值、启动后平均电流 |
| P1 | S0 睡眠 | `state 0` | LCD/背光关闭或低亮度、睡眠电流 |
| P2 | S1 近距离待机 | `state 3` | 角色动画、LCD、Wi-Fi 在线 |
| P3 | S1 远距离待机 | `state 4` | 降亮度、远距离待机 LED |
| P4 | S1 充电待机 | `state 5` | 充电指示和背光 |
| P5 | S2 陪伴 | `state 6` | 陪伴循环、道具动画 |
| P6 | S3 主动接近 | `state 9` | 前凑转换动画峰值 |
| P7 | S4 对话 | `state 13` | 麦克风、网络、屏幕、嘴型 |
| P8 | S5 沉默 | `state 17` | 低活动状态 |
| P9 | 5 分钟无操作呼吸模式 | `screen-timeout 300` 后等待 | 进入时间、背光 3%-20% 呼吸峰值 |
| P10 | 网络断开 | 断开 AP 或使用测试环境 | 重连间隔、离线状态电流 |
| P11 | 深度休眠 | `doze enter` | 休眠稳定电流和唤醒峰值 |

每条记录至少包含：日期、板卡编号、供电电压、平均电流、峰值电流、状态持续时间、固件版本和备注。

## 注意事项

- 不要把包含 Wi-Fi 密码、API Key 或 Token 的 `sdkconfig` 上传到公开仓库。
- 本仓库不提供生产密钥；测试人员需要使用自己的测试配置。
- UI 动画素材和语音网络请求可能产生较大瞬时峰值，应使用足够采样率的仪器观察。
